Η παρούσα διπλωματική εργασία πραγματεύεται την υλοποίηση αλγορίθμων

μια πρωτότυπη σύνθετη ευρετική (composite heuristic) που επιλέγει
δυναμικά τη βέλτιστη στρατηγική.

Τα πειραματικά αποτελέσματα επιβεβαιώνουν ότι ο αλγόριθμος Kociemba
επιτυγχάνει λύσεις κάτω των 19 κινήσεων σε λιγότερο από 5 δευτερόλεπτα,

databases, ευρετικές συναρτήσεις

### 6. Abstract - English (1 σελ.)
**Same structure as Greek, translate:**
```
This diploma thesis addresses the implementation of optimal solving
algorithms for the Rubik's Cube. Three algorithms were implemented:
Thistlethwaite's algorithm (4-phase), Kociemba's algorithm (2-phase),
and Korf's optimal algorithm using pattern databases.

Additionally, a distance estimation algorithm was developed and various
heuristic functions for the A* algorithm were studied. A novel composite
heuristic is proposed that dynamically selects the optimal strategy
based on cube state analysis.

Experimental results confirm that Kociemba's algorithm achieves solutions
under 19 moves in less than 5 seconds, while Korf's algorithm guarantees
optimal solutions (≤20 moves).

Keywords: Rubik's Cube, search algorithms, IDA*, pattern databases,
heuristic functions
```

## FORMATTING GUIDELINES

### Γραμματοσειρά και Μέγεθος
- Main text: Times New Roman, 12pt
- Chapter titles: 16pt bold
- Section titles: 14pt bold
- Subsection titles: 12pt bold
- Code: Courier New, 10pt

### Περιθώρια
- Left: 3.5cm (for binding)
- Right: 2.5cm
- Top/Bottom: 2.5cm

### Διάστιχο
- Main text: 1.5 line spacing
- References: Single spacing
- Code listings: Single spacing

### Αρίθμηση
- Pages: Bottom center, Arabic numerals
- Front matter: Roman numerals (i, ii, iii...)
- Figures: "Σχήμα X.Y" (Chapter.Number)
- Tables: "Πίνακας X.Y"
- Equations: Right-aligned (X.Y)

### Σχήματα και Πίνακες
- Caption below figures: "Σχήμα 3.1: Περιγραφή..."
- Caption above tables: "Πίνακας 4.2: Περιγραφή..."
- Reference in text: "...όπως φαίνεται στο Σχήμα 3.1..."
