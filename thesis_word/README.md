# Thesis - Word Version

## Structure

Copy each section below into your Word document in order.

## Files

1. `00_front_matter.md` - Title page, abstracts (copy to Word)
2. `01_introduction.md` - Chapter 1
3. `02_background.md` - Chapter 2
4. ... (one file per chapter)

## How to Use

1. Open Word
2. Set up document:
   - Page size: A4
   - Margins: Left 3.5cm, Right 2.5cm, Top/Bottom 2.5cm
   - Font: Times New Roman, 12pt
   - Line spacing: 1.5
3. Copy content from each .md file
4. Format headings using Word styles (Heading 1, 2, 3)
5. For equations: Insert → Equation → LaTeX mode
