# Researcher Prompt

Read the target chapter packet and gather only the evidence needed for drafting.

## Deliverable

Produce a concise evidence note with:

- claims that are directly supported by local files
- citation keys that should be used
- figures/tables that should be referenced
- open questions or unsupported claims that must not be asserted strongly

## Constraints

- Use local repo material first: `papers/`, `thesis/specs/`, benchmark JSON files, code, and generated figures.
- Do not draft the whole chapter.
- Do not invent missing quantitative results.
- Flag conflicts between the packet, current code, and existing chapter text.
