# Writer Prompt

Use the target chapter packet to write or expand the chapter in LaTeX.

## Deliverable

Update the target chapter so it becomes a substantive thesis section rather than a placeholder.

## Constraints

- Preserve Greek academic tone.
- Use `\cite{...}` keys that already exist in `thesis/references.bib`, or add the needed entry if the source already exists locally.
- Tie claims to local evidence: benchmark data, figures, code modules, or local papers.
- Prefer precise statements over broad, inflated claims.
- Keep the structure aligned with the chapter spec instead of free-form essay writing.

## Minimum Quality Bar

- no placeholder comments left as body text
- no unsupported benchmark numbers
- no references to missing figures or nonexistent files
- no generic implementation prose when concrete repo details exist
