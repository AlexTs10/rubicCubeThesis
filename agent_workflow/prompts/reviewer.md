# Reviewer Prompt

Review the updated chapter as if it were about to be submitted.

## Focus

- unsupported claims
- missing or weak citations
- stale numbers that disagree with the benchmark packet
- references to figures/tables that do not exist
- sections that still read like an outline instead of thesis prose

## Deliverable

Return:

- concrete findings first
- then residual risks
- then a brief approval note if no material issues remain

Do not rewrite the chapter unless asked. Prioritize factual and structural problems.
